本页怎么用

  1. 确认上面的时间是当前时间（手机时间不准就先校准）。

为什么会这样（缓存原理与一个限制）

GitHub Pages 给网页设了 10 分钟缓存，手机浏览器（尤其 iPhone 主屏幕图标）会直接拿旧副本，所以你更新了也看不到。本页把当前时间拼进网址（如 ?t=20261014142858），浏览器对不上缓存，只能去服务器取一次。

老实说一句：GitHub 的 CDN 只按路径缓存、忽略问号后的参数，所以刚推送后约 1～10 分钟内，服务器那边仍可能发旧副本。上面的「版本校对」会告诉你两个站各自最新一次提交是多久以前。

查人工具怎么用

  • 打开后顶部先选 周次 / 星期 / 节次，默认已按当前时间自动定位；右边可直接搜索姓名。
  • 逐人核对：一人一张卡片。橙色 个人差异课 指只有部分人有课，蓝色 全班共同课 指全班都上，绿色 应到自习 指该来上晚自习。
  • 卡片上方的小字给出统计（如「应到自习 N 人」）；上课人员筛选 可按课程名只看某些人。
  • 本周无固定节次的课 点开看军训、劳动教育、尔雅网课这类不按固定周次节次排的课。
  • 网格总览：行 = 姓名（按学号排序），列 = 星期，整周情况一眼看完。
  • 右上角可 切手机版 / 切电脑版，也能直接 打印 纸质核对表。

更多说明

两个目标网址分别保存在本机浏览器，换域名时在这里改，不用改代码。

时间戳每次点按钮都会重新生成，所以同一分钟内连点两次也是同一个新网址，不会重复下载。

「无缓存抓取」用 fetch(no-store) 直接抓该站最新 HTML 原地替换显示，是时间戳方式失效时的兜底；「直接打开（不校对）」不带时间戳，用于对比旧缓存。
